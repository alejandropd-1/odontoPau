# Paquetes sociales

Esta carpeta contiene derivados editoriales versionados que no forman parte del build publico del sitio.

Cada subcarpeta debe incluir:

- articulo fuente y version/fecha;
- estado editorial y aprobaciones;
- canales y formatos;
- copy adaptado por plataforma;
- inventario de assets y orden;
- CTA y enlaces medibles;
- resultados disponibles despues de publicar.

Estados sugeridos: `draft`, `clinical_review`, `approved`, `scheduled`, `published`, `needs_update`.

Si cambia un dato clinico del articulo fuente, el paquete vuelve a `needs_update`. No se programa ni publica una pieza sin aprobacion de Paula sobre el texto y las imagenes.
